WooCommerce loyalty, VIP, referrals, analytics, and an on-store AI commerce brain.

== Description ==

GrowthPilot awards purchase, review, signup, birthday, social, campaign, and referral points to the same customer wallet. Referral bonuses never use a separate balance.

Analytics covers revenue trends, AOV, LTV, repeat purchase, cohorts, retention, churn, product profitability, campaign ROI, email performance, funnel conversion, and attribution.

The AI Commerce Brain scores churn, next purchase, and high-value customers, suggests prices and discounts, and forecasts seasonal demand plus inventory — from WooCommerce orders, with an optional LLM only for narration.

== Installation ==

1. Activate WooCommerce, then activate GrowthPilot.
2. Open GrowthPilot in wp-admin to configure earn rules, VIP tiers, rewards, and referral campaigns.
3. Open GrowthPilot → Analytics and GrowthPilot → AI.
4. Customers use My Account → Loyalty and Referrals.
